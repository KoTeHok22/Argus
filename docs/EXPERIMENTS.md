# Эксперименты

Цифры — офлайн-прогоны `offline_detector` в образе `argus:dev`, ось «вперёд» −Y, габарит 3.0×2.1 м, земля — порог по Z. Конфиг: `argus_launch/config/argus_params.yaml`, SHA-256 `c401b96d401d0d7db5348dd3effe7b6dcd1ecccf0bbf0c53d206f77092efefbb`.

## Почему не нейросеть

Размеченное препятствие — один бэг из шести (`doubleT_obstacle`). Публичные веса 3D-детекторов — другой домен и часто non-commercial. На пустом тоннеле сеть либо не учится, либо запоминает стены. Геометрия нормы проверяется на platform и на `new_data`, которые организаторы дали позже.

## Производительность

| Шаг | Замер |
|---|---|
| Geometry (живой ROS, obstacle) | ≈ 42 мс/кадр |
| Fusion | 0.5–1.3 мс |
| Preprocess + range image | ≈ 6 мс |
| `--odometry` platform 200 кадров, после T24 | **87 мс/кадр** |
| Карта тоннеля `integrate` | 4% кадра после блочной сетки (T19) |

Полный `--tunnel` после ускорения ICP не переснимался. Для сдачи голос карты выключен: geometry + no-return + габарит + трек закрывают F-D.

## Компромиссы

- Габарит 3×2.1 м от головки рельса, как сказали организаторы. Боковой запас в `contains()` не входит — иначе край платформы даёт FP.
- Ось «вперёд» в кадре лидара — −Y, не +X. Без этого obstacle молчит.
- Карта тоннеля остаётся в конвейере, но не решает тревогу. Иначе платформа шумит, а бюджет кадра растёт.
