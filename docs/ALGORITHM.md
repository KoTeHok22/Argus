# Описание алгоритма

Статус: каркас. Заполняется по мере реализации фаз 2–4 (`PLAN.md`).

## Постановка

По каждому кадру ответить: есть ли препятствие в габарите движения поезда
и на каком расстоянии.

## Конвейер

1. **Sanity-фильтр** — отбраковка мусора (не-числа, `|coord| > 1e4`,
   дальность вне [0.5, 400] м) и отметка «нет возврата».
2. **Range image** — развёртка 2400×128, O(1)-соседи.
3. **Одометрия** — эго-движение с ограничением 4DoF (рельсы).
4. **Модель нормы** — карта свободного пространства (space carving по лучам)
   и/или гладкий профиль сечения.
5. **Три детектора аномалий** — нарушение свободного пространства,
   потеря возвратов, геометрический остаток.
6. **Габарит** — фильтрация по твёрдому телу (усечённая призма).
7. **Кластеризация** — связные компоненты на range image с адаптивным
   порогом по дальности.
8. **Трекинг** — подтверждение по кадрам, Kalman на центроиде, TTC.
9. **Тревога** — голосование признаков + подтверждённый трек +
   человекочитаемое объяснение.

## Почему три детектора

Один признак даёт либо пропуски, либо ложные срабатывания. Признаки
разной природы (нарушение карты, отсутствие сигнала, отклонение геометрии)
коррелируют слабее, чем любые два геометрических.
